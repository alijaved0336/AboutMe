## Engineering focus

- **AI systems that respect permissions.** I design retrieval around who can see each document, tie answers back to their sources, and use approval steps for agent actions. I track retrieval accuracy and execution failures to see where the workflow needs improvement.
- **Reliable data pipelines.** I build ingestion that can safely retry, handle duplicate events, and keep analytics queries fast as data volume grows. On Nomac, that meant optimizing ClickHouse schemas and using Redis to reduce API latency.
- **Full-stack delivery.** I work from database schema and API design through React interfaces and deployment. I lead design reviews, mentor engineers, and use CI/CD to make releases repeatable.
